## 🚀 Features

| Feature | Description |
|---|---|
| 👋 **Onboarding** | Guided setup flow for new users |
| 💬 **Real-time Chat** | Live messaging between users |
| 🔔 **Notifications** | In-app notification system with friend requests |
| 🎨 **Theming** | Customizable UI themes |
| 🔐 **Auth** | Sign up / login flow |

---

## 🛠️ Tech Stack

**Frontend:** React · Vite · Tailwind CSS

**Backend:** Node.js · Express · MongoDB
